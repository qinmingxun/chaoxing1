## 六、踩过的坑（务必避免重犯）

1. **改 loader.js 必须 node --check**：曾把版本串写成 单引号套单引号 → 整个内容脚本 SyntaxError → 扩展完全不注入（页面无面板无自动化）
2. **unipus.js 是 CRLF**：行级改写脚本必须规范化 \r\n，否则多行锚点匹配失败
3. **PowerShell 传 --host-resolver-rules 必须带引号**："--host-resolver-rules=\"MAP u.unipus.cn 127.0.0.1\""，否则参数被空格拆散、映射失效
4. **用户 Edge 的 Network/Cookies 有独占锁（EBUSY）** → 复制 profile 拿不到登录态；要么让用户重启带调试端口，要么在其窗口里登录一次
5. **面板/语音逻辑改动后要确认 appendChild 引用的变量都还在**（曾删掉 row1/row2 定义但保留引用 → ReferenceError → 面板消失）
6. **真机「没反应」先查**：data-course-helper-version 是否为最新 + 内容脚本是否有 SyntaxError
