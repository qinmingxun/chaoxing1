# u校园 AI 版 · 刷课助手 自测指南（v58）

> 适用版本：扩展 `v2026-10-20.58（题库连通性测试）`
> 环境：Edge 155 + 调试端口 9222 + 默认 profile（已登录 uai.unipus.cn）
> 面板位置：课程页右上角「刷课助手 · u校园」（关闭后右下角 ⚡ 悬浮球唤回）

---

## 1. 面板能力一览

| 区域 | 作用 |
|---|---|
| **⏹ 停止刷课 / ▶ 开始刷课** | 全局主开关：停止后不再动页面（答题/录音/视频/翻页全部停） |
| 状态行 | 运行中（自动答题 / 录音 / 视频倍速 / 翻页）或已停止 |
| 视频倍速 1x / 1.5x / 2x / 3x | 点击即时生效并持久化；每 2 秒巡检 `<video>` 拉回倍速，自动播放被拒时静音重试 |
| **DeepSeek API Key** | 输入框 + 👁 + 保存；右侧显示「已配置 / 未配置」 |
| **题库 API**（地址 + Key + 保存 + 测试） | 答题时**先查题库**，未命中/未配置/失败自动回退 DeepSeek；「测试」用一道示例题验证连通性 |
| ▶ 本页立即执行 | 手动触发一轮（停止状态下会提示先开始） |
| 实时日志 | 最近 30 条动作日志 |

答题优先级：**本地缓存 → 题库 API → DeepSeek**。命中题库的答案会写入本地缓存，下次同题直接复用。

## 2. 自测步骤

### 2.1 准备

1. 确认 Edge 已登录 `uai.unipus.cn`（未登录会被跳到 sso 登录页，面板仍显示但无法刷课）。
2. 进入课程 → 左侧目录选一节（有原音的语音题推荐 **1-2 Sharing / 1-5 Pronunciation**；普通题可选 Reading/Listening 下的节）。
3. 面板右上角确认版本为 `v2026-10-20.58`。

### 2.2 配置（可选）

- **只走 DeepSeek**：面板「DeepSeek API Key」填入 `sk-...` → 保存 → 右侧变「已配置」。
- **题库优先**：面板「题库 API」填入地址（可选 Key）→ 点「保存」→ 状态变「已启用（先查题库）」→ 点「测试」。
  - 预期日志：`题库测试：命中 ✓ 返回答案「B」`
  - 未命中：`题库测试：未命中（not-found）——答题时会回退 DeepSeek`
  - 失败：`题库测试：失败（...）`

### 2.3 开跑

点 **▶ 开始刷课**。预期日志（按页面类型）：

**语音题节**
```
u校园语音题：逐题循环开始（当前可见录音位 1 个；每题：录音 8000ms → 停止 → 下一题…）
u校园语音题：第 1 题开始录音点击已派发
u校园语音题：第 1 题已停止录音（dom-toggle）
u校园语音题：评分等待… → 第 1 题完成
u校园自动提交：已点击提交按钮
u校园提交已注入：answerCount=N，usedTime=… 秒
u校园自动翻页：已点击页脚翻页按钮
```

**普通题节**
```
u校园题目类型诊断（N 道）：#1 qtype=0 … #2 qtype=2 …
u校园选项点击：… → <label>…
u校园答案注入已就绪：N 道题，等待用户提交时自动注入
u校园提交已注入：answerCount=N
```

**视频节**
```
u校园视频：自动播放 + 倍速已启动（当前倍速 3x，每 2s 巡检）
```

### 2.4 验收清单

- [ ] 选择题自动选中正确选项
- [ ] 填空题自动填入答案
- [ ] 语音题自动录音→停止→下一题→提交
- [ ] 视频自动播放且保持设定倍速
- [ ] 提交后弹窗自动点「确定」、翻到下一节
- [ ] 平台不再弹「还有 N 道题没有作答」硬拦截
- [ ] 点「停止刷课」后页面不再被自动操作
- [ ] 题库「测试」按钮能正确报告命中/未命中

## 3. 常见问题排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 日志「有 N 道题未获得答案」 | DeepSeek Key 未配置 / 题库未命中且无 Key | 面板填 Key；或用题库「测试」确认题库连通 |
| 日志「题库 API 查询失败，继续 DeepSeek 求解」 | 地址/Key 错误、网络不可达、响应非 JSON | 点「测试」看具体错误；核对地址与 Key |
| 语音题录音后仍提示「还有 N 道题没有作答」 | 该页无原音（自由说话题），评测无法登记 | 先跑有原音的节预热语音缓存；已知限制，会自动跳过不卡死 |
| 日志「解密失败…降级为 DOM 提取」 | 加密题包无法解密 | 兜底跳过；把该节标题反馈给维护者 |
| 面板显示「已停止」且不动作 | 点了停止刷课，或 storage.autoAnswer=false | 点「▶ 开始刷课」 |
| 版本不是 v2026-10-20.58 | 内容脚本是旧版（扩展重载后需刷新页面） | 刷新页面 / 在 edge://extensions 重载扩展 |

---

## 4. 已知限制（如实告知）

1. **无原音的自由说话题**：页面没有音频元素 → 注入占位/缓存语音；若缓存未预热，评测不登记 → 平台硬拦截 → 自动跳过该页（不卡死，但该页题目不算完成）。
2. **少数加密题包解密失败**：取不到题目 → 兜底跳过。
3. **题库 API 需用户自备**：本项目不内置题库服务；未配置时自动回退 DeepSeek，不影响使用。
